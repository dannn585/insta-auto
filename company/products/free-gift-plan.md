- 渡す相手：Claude・AIで作業を自動化したい大学生・個人（リールを見て「AI」とコメントした人）
- 渡し方：コメント → DMでリンクを送る（marketing の導線：リール → プロフィール → 「AI」コメント → DM特典 → LINE → 商品）

## おすすめ：B案の理由
1. **実物がある**：このカンパニーは本当に動いている。「AI社員6人」のリールを見た人が一番欲しいのは、その実物の一部
2. **有料版との線引きがはっきりしている**：無料は「秘書1人」、有料は「6人の完全版」。足りない部分が自然に見えるので、売り込まなくても次が欲しくなる
3. **作る手間が少ない**：既存ファイル（CLAUDE.md・lin-company プラグインのエージェント・tasks.md・日報）を一般向けに書き直すのが中心
4. **プログラム知識が要らない道を用意できる**：Claudeデスクトップアプリにフォルダをつなぐだけで動くので、大学生にも渡せる（Claude Code は「さらに使いたい人向け」として後ろに置く）
5. A案の良いところ（すぐ使える指示文）は、B案の付録「秘書への最初の指示10個」として取り込める

一行で言うと：**「AIを毎回ゼロから使って続かない大学生・個人に、AI秘書が毎日の仕事を覚えてくれる仕組みを、無料（秘書1人分）で渡す」**

### 作るときの注意
- ダンのアカウント名・鍵・GitHubの場所など、個人情報や秘密情報は入れない（見本は「〇〇」などに置き換える）
- Claudeの料金プランや機能は変わることがあるので、本文には「2026年11月時点」と書く。数字（料金など）は書かない
- 「必ず稼げる」などの言い方はしない

## 本文の下書き（1〜5ページ）

### 1. 表紙

> **AI社員スターターキット**
> まずは「秘書」を1人雇う
>
> Claudeを毎回ゼロから使うのは、もう終わり。
> 指示を覚えて、毎日の仕事を一緒に回してくれるAI秘書の作り方。
>
> 対象：AIで作業を自動化したい大学生・個人
> 2026年11月版

### 2. はじめに

AIを使い始めた人の多くが、こんな状態になります。

- 毎回、同じ説明を一から打ち直している
- 便利な使い方を見つけても、次の日には忘れている
- 結局、たまにしか使わなくなる

原因は「指示の出し方」ではなく、**AIに覚えておいてもらう場所がないこと**です。

このキットでは、パソコンのフォルダ1つに「会社のルール」と「秘書の役割」を書いたファイルを置きます。Claudeは作業を始めるたびにそれを読むので、毎回の説明がいりません。

このキットで、できるようになること：
1. Claudeに「自分専用の秘書」としての役割を覚えさせる
2. やること・やったことを、秘書が表と日報に記録してくれる
3. 慣れたら、リサーチ係・文章係などの「社員」を少しずつ増やせる

むずかしいプログラムは使いません。ファイルをコピーして、何か所か書き換えるだけです。

### 3. 全体図：AI社員6人の会社

このキットは、私が実際に毎日使っている「AIの会社」をもとにしています。

```
            あなた（社長）
               │
          秘書（窓口）
   ┌──────┬──────┼──────┬──────┐
リサーチ  クリエイティブ  コミュニティ  マーケ  プロダクト
```

| 社員 | 仕事 |
|---|---|
| 秘書 | あなたとの唯一の窓口。やることを整理して、各部署に振り分ける。日報を書く |
| リサーチ | 伸びている投稿・競合を調べて、ネタを出す |
| クリエイティブ | 投稿の台本・文章を作る |
| コミュニティ | コメントやメッセージへの返信文を考える |
| マーケティング | 見てくれた人を、申し込みや購入までつなぐ流れを考える |
| プロダクト | 売るもの・渡すもの（資料や講座）を作る |

社員ごとに「役割」と「守るルール」を書いたファイルが1枚ずつあり、全員が同じ「タスク表」と「日報」を見て動きます。

このキットでは、このうち**秘書1人**の作り方を、コピペで使える形でお渡しします。

### 4. なぜ秘書から始めるのか

いきなり6人そろえると、だれに何を頼めばいいか分からなくなり、続きません。

秘書から始める理由は2つです。

- **話しかける相手が1人でいい**：「これやって」と秘書に言えば、整理して進めてくれます。あとで社員が増えても、窓口は秘書のままです
- **記録が残る**：秘書は、やることを「タスク表」に、やったことを「日報」に書きます。次の日に開いても、続きから始められます

1週間ほど秘書と仕事をすると、「調べものが多いな」「文章を書く仕事が多いな」と、次に必要な社員が自然に見えてきます。そのとき2人目を雇えば十分です。

### 5. 準備するもの

| もの | 必要か | メモ |
|---|---|---|
| Claudeのアカウント | 必要 | 無料プランでも試せます。毎日たくさん使うなら有料プランが快適です |
| Claudeデスクトップアプリ | 必要 | パソコンのフォルダをClaudeにつなぐために使います |
| パソコンのフォルダ1つ | 必要 | 名前は自由（例：「my-company」） |
| Claude Code（VS Code） | なくてOK | もっと本格的に使いたい人向け。12ページで紹介します |

※ Claudeの機能・プランは変わることがあります。2026年11月時点の内容です。

## 渡し方の案

| 方法 | 良いところ | 気になるところ | 評価 |
|---|---|---|---|
| Notion | 見やすい。コピペ用の枠（コードブロック）がそのまま使える。あとから直しても同じリンクで最新版になる。相手が「複製」して自分用に使える | Notionを知らない人には少しとまどう | ◎ おすすめ |
| Googleドキュメント | だれでも開ける。スマホでも見やすい | コピペ用ファイルの枠が見づらい。「コピーを作成」の説明が要る | ○ 予備 |
| PDF | 形がくずれない。保存されやすい | 直すたびに作り直し。PDFからのコピペは文字がくずれやすい（ひな形向きでない） | △ 印刷・保存用のおまけに |
| ひな形ファイル一式（zip） | そのままフォルダに置ける | DMでのファイル送信はできない。どこかに置く必要がある | 有料版向き |

おすすめ：**本体はNotionのページ1つ**（DMで送るのはリンクだけ）。12ページの最後でLINE登録に案内し、「完全版」の情報はLINEで流す。
※ Notionへの公開・リンク作成は、ダンの確認のあとで行う（今回はしていない）。
