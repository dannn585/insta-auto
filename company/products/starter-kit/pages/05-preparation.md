# 準備するもの

| もの | 必要か | メモ |
|---|---|---|
| Claude のアカウント | 必要 | プランによって使える機能や量が違います。下の「どの使い方にするか」を見て、自分のプランで使えるかを確かめてください |
| パソコン | 必要 | Windows でも Mac でもOK |
| パソコンのフォルダ1つ | 必要 | 名前は自由（例：my-company） |
| Claude デスクトップアプリ | おすすめ | パソコンのフォルダを Claude に読み書きしてもらうために使います |
| Claude Code | なくてOK | もっと本格的に使いたい人向け。12ページで紹介します |

## どの使い方にするか（3つから1つ選ぶ）

| 使い方 | 向いている人 | ひとこと |
|---|---|---|
| A. デスクトップアプリ＋フォルダ | ほとんどの人（おすすめ） | Claude がフォルダのファイルを読んで、タスク表や日報を自分で書き込みます |
| B. Claude Code | パソコン作業に慣れている人 | フォルダで起動すると CLAUDE.md を自動で読みます |
| C. コピペだけ | フォルダの機能が使えない人 | ファイルの中身を会話に貼り、Claude が書き直した内容を自分で保存します。手間は増えますが、仕組みは同じです |

- A の「フォルダを読み書きする機能」の名前や場所は、アプリの更新で変わることがあります。見つからないときは、アプリのヘルプや設定で「フォルダ」を探してください
- 使えるかどうかはプランによって違う場合があります。始める前に、自分の画面で確かめてください
