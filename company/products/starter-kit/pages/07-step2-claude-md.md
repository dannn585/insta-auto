# 手順2：会社のルール（CLAUDE.md）を置く

CLAUDE.md は、Claude が仕事の前に読む「会社の憲法」です。下の枠の中身を全部コピーして、フォルダの CLAUDE.md に貼り付けます。

```
# わたしの会社のルール

このファイルは、Claude に仕事の前に読んでもらう「会社のルール」です。
【 】の3か所を、自分用に書き換えてください。

## 会社のこと
- 社長：【あなたの呼び名】（例：たろう）
- 秘書：【秘書の名前】（例：ミナ）
- 目標：【いちばん達成したいこと】（例：12月までにES10社分を仕上げる／毎日1本SNSに投稿する）

## あなた（Claude）の役割
- あなたはこの会社の秘書です。動き方は agents/secretary.md に書いてあるので、最初に読んでください
- 社長からの依頼は、まず秘書が受けて整理します

## 記録の場所
- tasks.md：やること一覧（担当・期限・状態）
- reports/YYYY-MM-DD.md：日報（例：reports/2026-11-10.md）。書き方は reports/report-template.md
- knowledge/：調べたこと・決めたことのメモ。同じことを2回調べないために使う

## 全員が守るルール
1. 仕事の前に tasks.md と最新の日報を読む。終わったら更新する
2. 学んだこと・決めたことは knowledge/ に書き足す
3. 社長の確認が必要なもの：【確認してほしいこと】（例：お金の支払い・だれかへの送信・ファイルの削除・SNSへの投稿）。これらは下書きまでで止めて、tasks.md に「確認待ち」と書く
4. パスワード・カード番号・住所などの秘密の情報は、どのファイルにも書かない
5. 分からないことは決めつけず、社長に質問する
6. 社長への説明は短く、専門用語を使わない
```

## 書き換える場所は3つだけ

| 場所 | 書くこと | コツ |
|---|---|---|
| 1. 名前（社長・秘書） | あなたの呼ばれたい名前と、秘書の名前 | 秘書に名前をつけると、話しかけやすくなります |
| 2. 目標 | いちばん達成したいこと1つ | 「いつまでに・何を」まで書くと、秘書が優先順位をつけやすくなります |
| 3. 確認が必要なこと | 秘書が勝手にやってはいけないこと | お金・送信・削除・公開の4つは入れておくのがおすすめ |

書き換えたら【 】の記号は消してOKです。

## なぜルール3が大事か
秘書はとても働き者なので、頼んだ以上のことまで進めようとすることがあります。「ここから先はあなたの確認が必要」という線を先に引いておくと、安心して任せられます。

## 使い方ごとの読ませ方（2026年11月時点）
- A. デスクトップアプリ：会話の始めに「このフォルダの CLAUDE.md を読んでから始めてください」と言う
- B. Claude Code：フォルダを開いて起動すると、CLAUDE.md を自動で読みます
- C. コピペだけ：会話の始めに CLAUDE.md の中身を貼り付ける
