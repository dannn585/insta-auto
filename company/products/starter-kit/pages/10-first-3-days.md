# 最初の3日間

1日15分ほどで大丈夫です。毎回、会話の始めに「CLAUDE.md を読んでから始めて」と言ってから進めます（Claude Code の人は不要）。

## 1日目：やりたいことを秘書に全部話す
1. 秘書に「はじめまして。CLAUDE.md と秘書の設定を読んで、自己紹介して」と送る
2. 頭の中にある「やりたいこと・やらなきゃいけないこと」を、順番も気にせず全部話す（箇条書きでも、だらだら書きでもOK）
3. 「これを tasks.md に、期限つきで並べて」と頼む
4. 最後に「今日の日報を書いて」と頼む

できたかの目安：tasks.md にあなたのやることが並び、reports/ に今日の日報ができている

## 2日目：朝・夜の型を試す
1. 朝：「おはよう」と送る → 秘書が今日やることを3つまで提案してくれる
2. 日中：やったことを「〇〇終わった」と短く伝える → 秘書が tasks.md を更新する
3. 夜：「おつかれ」と送る → 日報と明日やることを決めてくれる

できたかの目安：前の日の日報を読んだうえで、続きから話が始まる

## 3日目：振り返って、2人目の社員を決める
1. 「この3日間の日報を読んで、うまくいったこと・面倒だったことをまとめて」と頼む
2. 「私の仕事で、いちばん多い種類はどれ？ 専門の社員を1人増やすなら、どんな係がいい？」と聞く
3. 秘書の答えを見て、増やす社員を1人だけ決める（12ページへ）

## うまくいかないとき
| こまったこと | 試すこと |
|---|---|
| ルールを読んでくれていない | 「CLAUDE.md を読み直して、ルールを3つ言って」と確かめる |
| タスク表や日報が書き込まれない | 使い方Aの人：フォルダを読み書きできる状態になっているか確かめる。使い方Cの人：秘書が出した内容を自分でファイルに保存する |
| 返事が長すぎる | 「結論から、3行で」と言う。気に入ったら secretary.md の「話し方」に1行足す |
| 前の日のことを覚えていない | 「reports/ のいちばん新しい日報を読んで」と言う |
