# 全体図：AI社員6人の会社

このキットは、私が実際に毎日使っている「AIの会社」をもとにしています。

```
                あなた（社長）
                     │
                秘書（窓口）
                     │
  ┌────────┬────────┼────────┬────────┐
リサーチ  クリエイティブ  コミュニティ  マーケティング  プロダクト
```

| 社員 | 仕事 |
|---|---|
| 秘書 | あなたとの唯一の窓口。やることを整理して、各部署に振り分ける。日報を書く |
| リサーチ | 伸びている投稿・ほかの発信者を調べて、ネタを出す |
| クリエイティブ | 投稿の台本・文章を作る |
| コミュニティ | コメントやメッセージへの返信の文案を考える |
| マーケティング | 見てくれた人を、申し込みや購入までつなぐ流れを考える |
| プロダクト | 渡すもの・売るもの（資料や講座）を作る |

社員ごとに「役割」と「守るルール」を書いたファイルが1枚ずつあり、全員が同じ「タスク表」と「日報」を見て動きます。

このキットでは、このうち**秘書1人**の作り方を、コピペで使える形でお渡しします。
（SNS以外の目的、たとえば就活・勉強・サークル運営でも、秘書の仕組みはそのまま使えます）
