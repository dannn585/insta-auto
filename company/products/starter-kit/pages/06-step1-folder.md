# 手順1：フォルダを作る

パソコンの好きな場所に、会社のフォルダを1つ作ります。中身は次のとおりです。

```
my-company/                 ← 会社のフォルダ（名前は自由）
├── CLAUDE.md               ← 会社のルール（手順2）
├── agents/
│   └── secretary.md        ← 秘書の設定（手順3）
├── tasks.md                ← タスク表（手順4）
├── reports/                ← 日報を入れる場所
│   └── report-template.md  ← 日報のひな形（手順4）
└── knowledge/              ← 調べたこと・決めたことのメモ
    └── README.md
```

## 作り方（どちらか）

**その1：自分で作る**
1. フォルダ my-company を作り、その中に agents・reports・knowledge の3つのフォルダを作る
2. メモ帳（Windows）やテキストエディット（Mac）などで、手順2〜4の中身を貼り付けて保存する

つまずきやすい点：
- ファイル名は大文字・小文字も含めてそのまま（CLAUDE.md は大文字）
- Windows で「CLAUDE.md.txt」になっていないか確認する（エクスプローラーの「表示」で「ファイル名拡張子」をオンにすると見えます）
- Mac のテキストエディットは「フォーマット」→「標準テキストにする」にしてから保存する

**その2：Claude に作ってもらう（使い方Aの人）**
1. 空のフォルダ my-company を作り、デスクトップアプリで Claude が使えるようにする
2. 「このフォルダに、次のフォルダとファイルを作ってください」と言って、上の図と手順2〜4の中身を貼り付ける
3. できたファイルを開いて、中身がそのまま入っているか確かめる

使い方C（コピペだけ）の人も、フォルダとファイルは同じように作っておきます。会話の始めに、ここから中身を貼り付けて使います。
