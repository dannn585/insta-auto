# 手順4：タスク表と日報のひな形

## タスク表（tasks.md）
フォルダの tasks.md に貼り付けます。最初の4行は、このキットの「最初の3日間」（10ページ）の内容です。

```
# タスク表

状態：未着手 / 進行中 / 確認待ち / 完了

| ID | やること | 担当 | 期限 | 状態 | メモ |
|---|---|---|---|---|---|
| T1 | 会社のルール（CLAUDE.md）を自分用に書き換える | 社長 | 1日目 | 完了 | |
| T2 | やりたいことを秘書に全部話して、このタスク表に並べてもらう | 秘書 | 1日目 | 未着手 | |
| T3 | 朝・夜の型を試す | 社長・秘書 | 2日目 | 未着手 | |
| T4 | 3日間を振り返って、2人目の社員を決める | 秘書 | 3日目 | 未着手 | |
```

- 表の形は秘書が保ってくれるので、あなたが表を直接いじる必要はありません。「T2を完了にして」と言えばOK
- 「確認待ち」は、秘書が「ここから先はあなたが決めてください」と止めているもの。毎朝ここを見るだけで、自分が何を決めればいいかが分かります

## 日報のひな形（reports/report-template.md）
reports フォルダの report-template.md に貼り付けます。秘書はこの形を見て、毎日 reports/2026-11-10.md のような日付のファイルを作ります。

```
# 日報 YYYY-MM-DD

## やったこと
- 

## 数字・結果
- （例：ESを2社分下書き／投稿1本／勉強60分）

## 分かったこと・決めたこと
- （ずっと使うものは knowledge/ にも書く）

## 次にやること
1. 
2. 
3. 

## 社長に確認してほしいこと
- （なければ「なし」）
```

## 知識のメモ（knowledge/README.md）
knowledge フォルダの README.md に貼り付けます。

```
# 知識のメモ置き場

調べたこと・決めたことを、テーマごとに1ファイルずつ書き足していく場所です。
例：knowledge/就活.md、knowledge/投稿のルール.md、knowledge/よく使う言い回し.md

秘書は、同じことを調べる前にまずここを確認します。
```

ここまでで準備は終わりです。
